Inside the Michigan eLibrary

Eight core databases, kept current and cross-linked, plus whatever else the library decides belongs in one place. The State Librarian has broad discretion to add reports, manuals, and other state publications that would otherwise take a dozen searches to find.

Citations that jump

Every citation inside a document is a link. Click a reference in a Supreme Court opinion and land directly on the statute, section, or order it points to.

Every version kept

When a statute is amended, the old text doesn't disappear. The current version and every prior version sit side by side, so you can see exactly what changed and when.

Data tables, downloadable

Each database can be exported as a data table — for a spreadsheet, a research script, an AI upload, or whatever else the work calls for.

CONST

Michigan Constitution

The state's founding text, with every amendment linked to the article and section it changed.

MCL

Michigan Compiled Laws

The full body of state statutes, current and as previously enacted, cross-linked to the Public Acts that created them.

MAC

Michigan Administrative Code

The rules state agencies operate under, linked back to the statutes that authorize them.

PA

Public Acts

Every act as signed, in the order it became law, linked forward to where it landed in the compiled laws.

ERO

Executive Reorganization Orders

The Governor's orders restructuring state government, with a record of what each order moved and when.

MSC

Michigan Supreme Court decisions

Opinions with every statute and prior case they cite linked directly to the source.

AG

Attorney General opinions

Formal opinions on how state law applies, indexed against the statutes and constitutional provisions they interpret.

Get a library card

A library card is the only requirement for eLibrary access — it's free, and it's what turns a search engine into a research tool.

What the card unlocks

The Michigan eLibrary is members-only. Once you have a card, every database, every linked citation, every archived version, and every downloadable data table is open to you — no per-document login, no paywall inside the system.

How the library operates

The Library of Michigan is an independent agency of the executive branch. It's headed by a State Librarian, appointed by the Governor and confirmed by the Legislature — Michigan's Legislature is unicameral, so a single confirmation vote is all a nomination needs.

Most services are delivered online through the eLibrary. The library also keeps a physical location in Flint, for anyone who prefers to do research in person.

The Library of Michigan's physical location is in Flint, Michigan. eLibrary access requires a library card; the physical location keeps its own posted hours.
